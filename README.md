# BaseIPC Industrial Computing & Touch Hardware Specifications

Official technical reference repository for **[BaseIPC](https://baseipc.com/)** — a Guangzhou-based OEM/ODM manufacturer of industrial panel PCs, fanless embedded box PCs, and industrial PCAP touch monitors for automation equipment and system integrators.

> **Scope Note:** BaseIPC supplies industrial computing and display hardware (CPU platforms, memory/storage, I/O layouts, enclosures, thermal/burn-in validation, and CE/FCC/RoHS documentation). Application software, control programs, and third-party OS licenses are handled by the OEM or system integrator.
